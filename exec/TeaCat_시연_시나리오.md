# TeaCat 시연 시나리오

## 1. 메인 페이지 및 광고 배너 확인

- TeaCat 메인 페이지 진입
- 메인 광고 배너를 통해 진행 중인 공연 확인
- 공연을 선택하여 티켓 예매 페이지로 이동

## 2. 공연 정보 확인 및 티켓 예매 시작

- 공연 상세 정보 확인
- 예매하기 버튼을 통해 좌석 선택 페이지로 이동

## 3. 좌석 중복 선택 방지 확인

- 이미 다른 사용자가 선택한 좌석을 클릭
- 선택할 수 없는 좌석임을 확인하여 중복 예매 방지 기능 시연

## 4. 좌석 선택 및 결제

- 선택 가능한 좌석을 클릭
- 선택한 좌석 정보를 확인한 뒤 결제 진행
- 결제 완료 후 티켓 발급 확인

## 5. 포토카드 팩 개봉

- 티켓 예매 보상으로 지급된 포토카드 팩 확인
- 카드팩을 개봉하여 랜덤 포토카드 획득
- 획득한 포토카드 정보 확인

## 6. 포토카드 경매 등록

- 획득한 포토카드를 선택
- 경매 판매 등록 진행
- 판매 가격 및 경매 정보를 설정하여 마켓에 등록

## 7. 포토카드 마켓 거래

- 포토카드 마켓으로 이동
- 다른 사용자가 등록한 포토카드 확인
- 원하는 카드를 선택하여 구매
- 구매 후 자신의 보관함에서 카드 소유권 변경 확인

## 8. 관리자 페이지 이동

- 사용자 시연 종료 후 관리자 페이지로 전환
- 공연 입장 관리 화면 진입

## 9. 티켓 스캔 및 유효성 확인

- 사용자의 티켓을 스캔
- 정상적으로 발급된 티켓인지 확인
- 이미 사용된 티켓이나 유효하지 않은 티켓의 중복 입장을 방지

## 10. 얼굴 인증 및 최종 입장

- 티켓 확인 후 얼굴 인증 진행
- 등록된 사용자 정보와 얼굴을 비교
- 인증 성공 후 최종 입장 처리
- 관리자 화면에서 입장 완료 상태 확인

## 전체 흐름

공연 발견 → 티켓 예매 → 좌석 중복 방지 → 결제 → 포토카드 획득 → 경매 판매 → 마켓 구매 → 티켓 검증 → 얼굴 인증 → 입장
