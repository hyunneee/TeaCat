# 아이콘

`logo.svg` 는 **티캣 로고**입니다 — 티켓 한 장의 위쪽 두 귀퉁이를 고양이 귀로 세운 형태.
앱 안의 마스코트(`src/shared/components/ui/CatMascot.tsx`)와 같은 형태라 앱과 앱 아이콘이 이어져 보입니다.

PWA 설치 아이콘 PNG 를 여기에 넣어주세요. **아직 없습니다.**

| 파일 | 크기 | 용도 |
|---|---|---|
| `logo.svg` | - | 브라우저 탭 파비콘 ✅ 있음 |
| `pwa-192.png` | 192×192 | 안드로이드 홈 화면 |
| `pwa-512.png` | 512×512 | 스플래시 / 스토어 |
| `pwa-maskable-512.png` | 512×512 | 안드로이드 적응형 아이콘 (가장자리 20% 여백 필수) |
| `apple-touch-icon.png` | 180×180 | iOS 홈 화면 |

`logo.svg` 를 512px PNG 로 내보내면 나머지는 https://realfavicongenerator.net 에서 한 번에 만들 수 있습니다.
아이콘이 없으면 설치는 되지만 홈 화면에 회색 네모로 뜹니다.

> maskable 아이콘은 가장자리가 잘리므로, 귀가 잘리지 않게 여백을 넉넉히 두고 내보내세요.
